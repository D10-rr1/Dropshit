# Emberwell – one-product store (rechargeable hand warmer)

**Live preview:** https://emberwell-store.vercel.app

A fast, standalone store website hosted on Vercel (free). No Shopify, no domain needed yet.

| What | Where |
|---|---|
| Website (homepage + product + cart) | `site/index.html`, `site/styles.css`, `site/app.js` |
| Product images (placeholders) | `site/img/` |
| Policy & contact pages | generated by `tools/build_pages.py` → `site/*.html` |
| Vercel settings | `vercel.json` |
| Why this product won | `store-setup/WINNING-PRODUCT.md` |
| Facebook ad plan + video scripts | `store-setup/facebook-ads.md` |

## What works now
- Homepage with hero, benefits, product section, how it works, comparison table, gift section, guarantee, FAQ
- Bundle picker (1 / 2 / 4 sets) with real savings, cart drawer that remembers items, sticky "Add to cart" bar on mobile
- Live delivery-date estimate
- Shipping, refunds, privacy, terms and contact pages
- Works on phone and desktop

## What's still needed before taking real orders
1. **Real product photos/video.** Replace the drawings in `site/img/` with photos from your supplier (or your own sample).
2. **Payments.** Create a free **Stripe** account, then make one **Payment Link** per pack ($34.99 / $59.99 / $99.99,
   with shipping-address collection on). Paste the 3 links into `CHECKOUT_LINKS` at the top of `site/app.js`.
   Until then, "Checkout" shows a preview message.
3. **Support email.** Replace `support@emberwell.example` in `site/index.html` and `tools/build_pages.py`.
4. **Domain (when you're happy).** Buy one in Vercel → Project → Settings → Domains. It connects automatically.
5. **Facebook Pixel.** Paste your Meta Pixel code into the `<head>` of `site/index.html`.
6. **Supplier.** Use CJdropshipping or AliExpress and place each order there manually (or with an order-sync app) when
   a Stripe payment comes in.

## Editing and redeploying
Edit files in `site/`. If you change the header or footer in `site/index.html`, run
`python3 tools/build_pages.py` to update the other pages. Vercel runs that script on every deploy.
